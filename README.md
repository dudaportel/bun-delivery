# Bun Delivery 🐰📦

A 2D platform game developed in Unity where players help a bunny deliver packages across increasingly challenging environments.

## Overview

Bun Delivery is a small game project created to explore game development concepts using Unity and C#.

The game features a complete gameplay loop, including:

* Main Menu
* Tutorial Level
* Advanced Delivery Level
* Win and Game Over Screens
* Scene Transitions
* Background Music
* Pixel Art Assets

## Gameplay

### Tutorial

Learn the controls and complete your first package delivery.

### Phase 2

Carry a stack of packages while avoiding falling ice obstacles and reach the mailbox safely.
